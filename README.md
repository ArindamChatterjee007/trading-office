# Trading Research Office

Personal paper-research mobile app:
https://arindamchatterjee007.github.io/trading-office/

This repository contains only the audited static production bundle. It contains
no broker credentials, phone pairing key, private alert history or account data.
The separate private phone bridge requires authentication and an awake laptop.

No live trading, automatic orders, guaranteed returns or loss limits. Background
phone delivery requires device installation/permission and a registered push
subscription. GitHub Pages does not run the Python research engine or AI agents.
